# v5 dependency maintenance

This fork remains on Sourcebot v5.1.16. The baseline branch `nett/v5.1.16` and
Zoekt commit `b762b16dde4bee0eaae3faa56c7e195c8e2ad341` remain unchanged.
No upstream main/v6 code, EE files, licence or copyright files were changed.

## Package changes

The manifests select current stable patch/minor versions. The refreshed Yarn
lockfile is deduplicated, including CodeMirror state to avoid duplicate extension
identities. The package-level diff is [npm-lock-changes.csv](npm-lock-changes.csv).

The development-only tools concurrently, cross-env and dotenv-cli take current
major versions without changing the existing command syntax. Other deferred
majors and selected versions are listed in [deferred-npm.csv](deferred-npm.csv).
They require separate compatibility work, not a blanket claim of safety from a
successful installation.

The AI SDK family is explicitly pinned at baseline after its newer tool
description/execution contracts caused eleven errors in unchanged EE TypeScript
consumers. The captain approved deferring those updates rather than editing EE.
Its residual provider-utils advisories are retained and reported below.
`@types/psl` stays at1.1.3 because the newer1.11.0 is an empty deprecated stub
that prevents TypeScript compilation. No tests or type checks were bypassed.

The only hand-written source compatibility changes preserve runtime behaviour:
an explicit generic prompt-export type and deriving the review agent's GitHub
pull-request type from its actual Octokit client rather than an unrelated
hoisted OpenAPI-types package. The PostHog transport test expects the updated
SDK version. The query parser is regenerated by the updated Lezer generator.

## Go and base images

The pinned Zoekt code is built with the generated module overlay in
`vendor/zoekt-dependencies/`. Docker and `make zoekt` use it. This avoids an
unpublished submodule commit or a second fork. Changes are listed in
[go-module-changes.csv](go-module-changes.csv).

```sh
cd vendor/zoekt
go test -modfile=../zoekt-dependencies/go.mod -mod=readonly ./...
```

Retained go-enry2.9.1 because2.9.6 changes the returned language name from
Mathematica to Wolfram Language and fails the unchanged language test. Retained
gobwas/glob0.2.3 rather than taking major1.1.0. Major-versioned module-path
migrations, such as go-github/v78 to a newer /vN, are outside this patch/minor
refresh. No newer Zoekt code is imported from its non-descendant upstream main.

The image uses digest-pinned Node24.22.3 on Alpine3.23 and Go1.26.11 on
Alpine3.24, preserving each existing line. Runtime Alpine packages are upgraded
by the existing Dockerfile. The required universal-ctags6.1.0 compatibility pin
is unchanged.
